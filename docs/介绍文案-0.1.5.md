① 一句话简介
DSH Desktop（鸿蒙版）——把开源 AI Agent 工作台 DSH 装进鸿蒙电脑：多会话对话、工具调用、文件读写、技能与插件市场，一站式完成。

② 应用介绍
DSH Desktop 是面向开发者与技术用户的 AI Agent 工作台鸿蒙桌面版，基于开源项目 DSH 构建，完整复用其 Web 界面，在鸿蒙 2in1 / 平板设备上提供与桌面端一致的使用体验。

主要功能：
- 多会话对话：围绕工作区开展多轮 AI 对话，会话本地持久化并支持全文检索。
- Agent 与工具调用：AI 可自主调用文件读写/编辑/搜索/删除/移动/复制、命令执行等工具完成实际任务（命令执行使用系统自带 sh/toybox）。
- 技能与插件市场：内置插件市场与运行时技能，可按需扩展 Agent 能力。
- 图片附件：支持在对话中附加图片，解码/转换走平台图像框架。
- 桌面体验：窗口状态记忆、F11 全屏、状态栏图标、快捷方式（打开新窗口）。

使用说明：本应用需自行配置所用大模型的 API Key（设置 → 模型）。应用内文本内容由 AI 生成，仅供参考，请自行核实。
其他说明：本应用不内置模型运行环境；插件市场的「一键安装」依赖设备上已具备的 pnpm，属可选能力，不作为产品功能承诺。
